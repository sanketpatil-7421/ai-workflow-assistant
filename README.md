🧮 Python Calculator

A simple command-line calculator written in Python. It performs basic arithmetic operations: addition, subtraction, multiplication, and division.

✨ Features
➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
⚠️ Handles division by zero
🚫 Handles invalid operations
🐍 No external dependencies
🚀 Run
python calculator.py

💡 Example
Enter first number: 10
Enter second number: 5
Enter operation (+, -, *, /): *

Result: 50.0

📋 Supported Operations
Operation	Description
+	Addition
-	Subtraction
*	Multiplication
/	Division
📁 Project Structure
project/
├── calculator.py
└── README.md

⚠️ Error Handling

The calculator displays Cannot divide by zero when attempting to divide by zero and Invalid operation for unsupported operators.
